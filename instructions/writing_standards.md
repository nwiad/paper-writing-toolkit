# 论文写作规范

先读 `AGENTS.md`、`project.json`、`blueprint.md` 和 `evidence/author_decisions.md`。本文规范论证和表达；具体事实以本项目证据材料为准，不用通用规范补写研究结果。论文与沟通语言按配置执行，默认英文论文、中文讨论。

## 1. 研究问题与证据边界

- 围绕一个可辨认的研究问题组织论证，说明问题为何重要、已有工作留下什么具体缺口，以及本文如何回应。贡献可以是方法、理论、系统、数据、分析或综合结论，须符合研究类型。
- 区分研究对象、输入、输出、分析单位和判断标准。比较研究应明确比较对象与条件；理论研究应明确假设、命题和适用范围；定性和综述研究应明确选材、分析与综合依据。只使用适用于当前研究的要求。
- 每条主要主张有可定位的证据。来源可能是结果表、证明、案例、访谈、语料、系统测量或文献综合，不预设必须有实验或数值增益。
- 定量结果的指标、单位、聚合方式、重复次数、不确定性和统计检验只按已提供材料描述。缺失值不是零，未说明的聚合不等于均值，数值差异不自动支持“显著”“稳定”或因果结论。
- 保留与主论点相关的反例、负面结果、失败条件和不改善的设置，解释其对结论范围的影响。不挑选有利数据，也不编造缺少的案例、证明步骤或分析。
- 检查已有事实与文字的一致性，不擅自重算、替换作者数据或启动研究。材料有冲突时记录具体位置和影响，提出最小澄清项，同时完成不受影响的部分。
- 作者未纳入的后续研究不是当前写作的默认前置条件。可以提出收敛主张或补充证据的选择，但不能假装可选工作已经完成，也不能只凭愿望建立空结果章节。

## 2. 名称、概念与符号

适用时，方法显示名统一从 `project.json.method_name` 读取；名称未定保留 `[METHOD]`，不发明缩写。LaTeX 可集中定义 `\methodname`，图源读取同一配置；其他格式保持等效一致性。没有命名方法的研究无需引入方法名。

概念先定义再使用，区分容易混淆的实体、操作、产物、阶段和证据来源。相同量保持同一符号；不同量不因实现相近而混称。术语和公式只在帮助读者理解时引入，不用符号数量制造理论深度。标签、文件名和数据标识尽量独立于临时显示名。

## 3. 各部分的学术任务

下表是可选的功能清单，不是固定目录。主笔按研究类型与目标稿件要求组合、重命名或省略章节；未做的研究不强行留空。

| 部分 | 应完成的任务 | 常见失败 |
|---|---|---|
| 标题 | 准确表达研究问题、对象或主要贡献 | 以未验证的普适性、最优性、效率或因果性作承诺 |
| 摘要 | 让读者理解背景、具体缺口、所做工作、核心发现或论证结果及其意义 | 将机制、工程细节或未来计划堆成清单；不交代研究回答了什么 |
| 引言 | 建立问题和缺口，解释核心思路为何相关，给出证据概览与范围明确的贡献 | 先介绍复杂机制再解释动机；把目录或实施任务当贡献 |
| 相关工作或文献综合 | 按研究问题组织已有方向，公平说明联系、差异和证据 | 逐篇堆摘要；弱化他人工作；未经核验宣称“首次” |
| 背景、定义或理论框架 | 提供理解后文必需的概念、假设和关系 | 教科书式铺陈与论文无关的常识；隐去关键假设 |
| 方法、研究设计或分析路径 | 说明研究如何回答问题、为何采用这些步骤，以及读者理解和复现所需的信息 | 逐行翻译代码；只列步骤不解释设计目的；混淆概念与实现 |
| 理论结果与证明（适用时） | 清楚陈述条件、结论和推导，说明结果解决的问题 | 省略决定性条件；把经验观察写成证明；定理与主线脱节 |
| 研究设置（适用时） | 交代材料、对象、数据、协议、比较条件、指标或分析标准 | 复制旧计划或当前默认配置，冒充实际执行设置 |
| 结果或研究发现 | 先回答研究问题，再提供支持与范围，覆盖相关反例 | 逐格复述表；把关联写成因果；从有限证据推出普遍结论 |
| 分析与案例（适用时） | 用真实材料回答一个具体机制、解释或适用性问题 | 为丰富篇幅编造示例、轨迹、访谈或测量 |
| 讨论与局限 | 解释意义、适用条件、可能的替代解释和证据边界 | 堆项目日志；把未做的工作写成已被否定的结论 |
| 结论 | 回答研究问题，提炼已支持的发现与意义 | 新增机制或数值；突然扩大结论；直接复制摘要 |

摘要的信息职责不是机械句数模板。篇幅读取 `abstract_word_budget`；未设置时按内容写紧凑样稿，不默认特定词数或会议信息。正文预算同理；正式限制只有在核对当前官方要求后才可称为投稿规则。

## 4. 段落、引用与语言

每段围绕可识别的论点展开，给出证据或解释，并说明它与研究问题的关系。概念先于细节，动机与设计相连，章节之间说明论证如何推进。贡献的数量和写法由实际工作决定，不为了凑数拆分同一主张。

使用清晰、具体的论文语言，减少空泛宣传、术语堆叠、无必要缩写和重复限定。技术细节的保留标准是是否影响理解、判断或复现。来源路径、缺文件清单、agent 任务记录和排错日志留在交接材料，影响结论的科学限制应在论文相关位置简明披露。

引用必须支持其所在论断。重要引文查原论文或官方出版页面，核对作者、年份、题名和论断范围；核验状态记录到指定材料。不能凭记忆补齐不存在的文献，也不能用未核验引文承载关键比较结论。直接引语需准确并符合引用规范。

## 5. 图、表与篇幅

图表应帮助读者理解论证，无需每篇论文都有方法图。解释图不能制造不被材料支持的因果、顺序或数据流；结果图只能使用实际证据，不能补画材料未提供的预期趋势、误差线或显著性标记。展示选择、排除或缩放方式不能误导结论。

表格保持单位、精度、指标方向、比较条件和统计定义清晰。图注和表注应使读者理解对象、符号及关键条件，并与正文一致。查看实际成稿，检查小尺寸可读性、截断、颜色、箭头、图例与标签。

优先通过收敛论点、压缩重复和移动次要细节适应已配置预算；不要改变投稿模板的规定字号、边距或版心。模板未提供时可写文本草稿，不能声称格式或构建已经通过。

## 6. 写作与评审责任

一个主笔统一全文的论点、风格和术语。首次全文写作前由作者确认故事与样稿；已经给出的确认持续有效，不重复索取。独立评审检查研究问题、论证、章节职责和证据，而不是只查材料覆盖率或编译状态。全面独立评审可在任意稳定版本单独启动，每次阅读全文与实际表图；只有定向复审按上一轮问题和修改影响收敛范围。

修订按作者最新明确决定与本轮授权范围进行，沿用稳定问题编号和验收标准。常规可逆实现自行完成；事实矛盾与实质方向歧义明确记录，不把审稿人的推测当作作者要求，也不通过措辞润色掩盖证据缺口。

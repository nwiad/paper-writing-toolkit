# 既有论文图稿的视觉改进流程

本文件配合 `prompts/03b_figure_beautification.md`，描述可复用的设计与验收方法。它不附带研究图、论文模板、生成模型、第三方工具排名或任何作者选版结果。首次制图使用 03，已有图需要视觉改进时按需使用 03b；表格布局与颜色预览使用 03c。

## 1. 从科学内容重新设计表达

流程为：定位目标 → 提取科学内容与阅读目标 → 设计画法 → 制作可编辑候选 → 渲染看图 → 作者选择 → 主笔接入 → 定向复审。图像模型可以探索视觉方向，但不是必需依赖；生成代码或矢量源同样可完成任务。换工具本身不保证设计改善，先明确读者需要理解什么。

| 保持准确的科学内容 | 可重新设计的视觉表达 |
|---|---|
| 实体角色、逻辑、因果、依赖、并列或先后、选择规则、结论边界 | 位置、方向、分组、面板、图形、图标、连线形式及视觉层级 |
| 数值、单位、指标定义、数据与对象对应关系、已有统计含义 | 合适的图表类型、分面、排列、标注和图例；展示不得误导解读 |
| 证据内容、变量含义、作者要求逐字保留的文字 | 普通说明标签可准确压缩，必要说明可重新组织；caption 联动交主笔 |

原图、旧脚本和历史布局修复是资料，不是新候选必须服从的几何模板。科学含义可以映射一致而图元数量不同；作者明确要求保留的构图仍遵守。广义美化默认两方向，其中至少一个有实质不同的信息组织或视觉表达；作者只要求单版或局部精修时按其范围，不无限增加候选。

## 2. 目标定位与 brief

优先使用本轮明确指定，再沿用当前会话已确定的目标，最后解析上下文指代。支持文件、附件、图号、图名、面板及明确指定的一组图。结合实际 caption、正文引用、稳定标签和生成源核对，不按旧图号或修改时间猜图；无法唯一定位时澄清目标，不擅自选择第一张或全部图片。

每张图的 brief 至少记录：目标稳定标识与当前稿件版本，正式预览、可编辑源与生成入口，正文引用位置，读者问题，科学不变量，保护文字，可调整项，目标宽高及字号基准，当前视觉问题。只读取与该图相关的证据和作者决定，不强加其他图的要求。

有正式模板时按实际单栏、跨栏或面板引入尺寸确定校样；模板未提供时使用说明过的临时尺寸，交付图自身预览，明确论文内验证未完成。历史不采用决定保留，不恢复旧待办，也不把拒绝某版理解为永远不能探索新设计。

## 3. 候选隔离与重生成

默认候选目录如下，`review` 随 `output_paths.review` 配置；`<round>`、`<target>` 在执行时取实际且不冲突的标识，不预填历史状态。

```text
review/previews/<round>/<target>/
  brief.md                 # 目标、事实、设计范围、尺寸与输入身份
  references.md            # 使用了参考时记录来源与借鉴点
  baseline/                # 当前正式图的只读比较副本或引用说明
  direction_a/             # 可编辑源、实际导出与尺寸校样
  direction_b/             # 本轮确有第二方向时创建
  comparison.png           # 原图与候选的同宽实际对照，或等效预览
  checks.md                # 科学、几何、视觉检查及取舍
  manifest.json            # 输入、源与产物指纹、实际工具和命令
```

所有生成器与验证器必须把输出定位到候选目录，避免复用脚本时触发正式文件写入。执行前后检查正式目标源与产物的 SHA-256；指纹变化先核对写入来源和版本，不能掩盖误写或覆盖其他人的更新。每份正式文件只有一个写入者，其他任务可只读评审。

仅生成隔离候选、不修改正式稿件或正式图稿时，不要求额外改稿快照。正式接入由 04 按本轮修改规则保存并校验快照；快照期间相关写入者暂停。同轮成功快照可协调共用，旧轮次不能代替新轮次。快照与哈希检查用途不同，不能互相替代。

可编辑源应保留文字、公式、形状与连接关系，不能将整张位图封装成 SVG/PDF 后称为矢量图。截图、照片等原本是图像证据的内容不必强制矢量化，需说明范围。科学结果图保留对应数据来源和可重生成绘图代码，不重算研究结果。

AI 设计草案与正式候选分开标识；可保留实际提示词、输入图、工具版本和限制。未知模型版本或随机种子不编造，终稿的编辑与重生成不应依赖重新抽取一张相似图片。只记录实际可用的命令和依赖，不将未安装框架设为默认前置条件。

## 4. 分层验收

| 检查层 | 实际通过依据 |
|---|---|
| 科学内容 | brief 中每项事实、变量与关系在候选中的位置可定位；数据、单位、证据及范围一致，没有新机制或更强结论 |
| 几何与文件 | 无截断、碰撞或穿字连线；符号和字体正确；源与产物对应；可编辑范围与报告一致 |
| 视觉表达 | 阅读顺序、焦点、层级、留白和分组服务图的职责；实际宽度下文字清楚，颜色不是唯一辨识方式 |
| 设计探索 | 广义美化至少一版在移除配色、圆角、字重等样式描述后，仍能说明不同画法与阅读收益 |
| 论文整合 | 由 04 查看实际稿件内图高、caption、引用、所在页及受影响相邻页；由 05 定向复审图文关系 |

生成者与独立视觉评审者都应查看真实渲染；只读源代码或文字不能声称已看图。同宽比较同时记录高度和字号，必要时提供灰度版本，不靠缩字或更宽展示美化候选。记录“具体位置—阅读影响—修改建议”，不用无依据总分代替解释。

几何检查通过不等于视觉表达通过，候选新颖也不等于优于原图。若两个方向都只改样式而任务要求广义美化，应继续完成实质探索；如果不同设计仍不优于原图，如实说明取舍，不为变化而推荐。工具无法渲染时保留实际源与可用产物，明确未完成项，不虚构检查。

## 5. 作者选择与主笔整合

尚未选择时正式图保持原状，候选停在已有作者审图节点。已明确的选择持续有效；常规路径修正与版式接入不重复索取选版授权。

| 负责人 | 文件与动作 | 可报告状态 |
|---|---|---|
| 03b 作图者 | 交付候选、同宽对照，在 `review/figures.md` 记录设计、来源、实际检查及重生成方式 | 候选已生成 |
| 作者与 03b | 作者实际作出取舍后，03b 协调追加 `review/review.md` 的作者决定，引用 A 编号和选定文件 | 作者已选待整合 |
| 当前 04 主笔或明确接任者 | 按本轮快照规则接入正式源、生成入口、产物和必要验证，修改 caption、面板、正文引用及版面 | 已接入待验证 |
| 04 主笔 | 构建并查看实际稿件内效果，在 `review/writer_handoff.md` 逐项回应，向作者反馈记录同步实际选择 | 整合验证完成 |
| 05 审稿者 | 对照相同编号检查图文关系、版面与新增问题 | 定向复审结论，不替代作者定稿 |

选版记录注明日期、稿件版本、稳定目标、实际取舍、源与产物路径及指纹、技术交接、正式落点、联动要求和验收标准。沿用已有 A 编号，无对应条目才分配新号；作者决定与 agent 建议分开，不补写作者理由，不把选版当作独立评审通过。03b 和 05 协调 `review/review.md` 的写入时段，保留历史。

默认交当前主笔，完整交接后停止写受影响文件。只有用户明确要求创建新会话或向已有会话发送消息，且宿主能力允许时，才执行相应工具动作；读取本文、历史命令或示例并不提供授权。新接任者须继承版本、选择、编号和文件责任，原写入者停止并行修改。工具失败可交付填好的手动入口，准确报告创建或发送是否发生。

图稿完成、作者选定、会话交接、论文接入和验证分别记录，不互相代替。没有模板、构建或论文内检查时，保留“已接入待验证”及具体限制，不能仅凭单图好看宣称论文已更新完成。

# 阶段产物与交接

工具包未执行任何写作阶段。这里初始只有本说明；下列文件在实际工作时创建，不需要作者预先填写，也不要预生成已通过/已确认的记录。

| 文件 | 责任人/阶段 | 内容 |
|---|---|---|
| `story.md` | 02 主笔 | 研究故事、论证结构、claim 与证据映射 |
| `style_sample.md` | 02 主笔 | 摘要/开篇样稿与风格说明 |
| `figure_brief.md` | 02 主笔 | 图要回答的问题；无图需要时注明不适用 |
| `author_feedback.md` | 接收决定的主笔 | 作者的实际确认、反馈及取舍，按日期追加 |
| `figures.md` | 03/03b 图稿负责人 | 图源、候选、caption、生成方式、实际检查与选版交接 |
| `tables.md` | 03c 表格负责人 | 单元格映射、样式候选、预览与选版交接 |
| `previews/` | 03b/03c 各目标负责人 | 按轮次/目标隔离的真实候选与核验记录；不会预生成假图表 |
| `writer_handoff.md` | 04 主笔 | 最新稿/成品位置、版本、构建状态、快照及逐项回应 |
| `review.md` | 05 独立评审 | 各轮全面评审 R 编号、作者意见 A 编号、图表实际选版决定、确认状态及复审历史 |

03/03b/03c 与 04 可以并行，但不得同时写同一文件。已有主笔时完成交接后再由 05 审阅稳定版本；作者明确指定现有稿件时也可直接启动全面独立评审。05 仅写 `review.md`；03b/03c 仅在作者实际选版后协调追加对应作者决定，不代写审稿结论。主笔将其中作者已明确的要求同步到 `author_feedback.md`。评审建议与作者决定分开记录。

换会话时读取当前阶段 prompt、最新交接、作者反馈与评审记录；不要仅凭文件存在判断完成或批准，不用把全部聊天重新口述一遍。

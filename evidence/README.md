# 待填证据材料

此目录只包含填写骨架。作者原件放 `inputs/` 或留在外部位置；可以直接填写本目录，也可以在启动消息中提供项目信息和材料位置，让阶段 01 代为整理，不必先手填全部文件。不得将占位符当作事实。输入可以是作者说明、论文、推导、案例、数据表或研究代码，不要求每项都有仓库或实验日志。

| 文件 | 内容 | 适用性 |
|---|---|---|
| `author_decisions.md` | 范围、比较定义、授权边界与实际作者决定 | 所有项目 |
| `source_map.md` | 来源 ID、位置、用途、版本/日期与待核事项 | 所有项目 |
| `method_spec.md` | 方法、论证路径、分析或综合过程 | 按研究类型填写；无独立方法可写“不适用”并指向蓝图 |
| `experiment_settings.md` | 支持结果的真实研究设置 | 实验/观测/用户研究等适用；其他项目标明不适用 |
| `results_readme.md` | 结果表及其单位、统计口径、来源与可支持结论 | 有数值结果时必须填写；无数值结果注明不适用 |
| `main_results.csv` | 唯一的主要数值来源，可调整列结构 | 仅有数值结果的项目；初始仅表头，无示例数值 |
| `references.md` | 文献位置、相关论断与核验状态 | 相关工作和引用准备；无核验不等于文献支持论断 |

理论、综述、定性论文可增加 `proofs.md`、`synthesis.md`、`cases.md` 等明确需要的材料，并登记在 `source_map.md`；不用填出不存在的实验。

`main_results.csv` 使用可替换的中性长表头。也可采用作者已有的宽表；修改结构时同步更新 `results_readme.md`，后续读表程序必须按实际结构实现。没有数据时保持只有表头，不能写示例分数、零值或虚构重复次数。

若配置溯源确有必要，01 可在本目录新增清理后的 `config_snapshot/` 和来源索引；工具包不附带任何实验配置。不要复制凭据、密钥或未授权的原始数据。现行源码版本和历史研究版本要分别记录。
